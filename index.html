重新理解 If 假設句型

假設句型在傳統文法書的教學中，充斥著片面且脫離實際使用方式的規則。這個互動式網頁將幫助學生透過觀察規律的學習路線，用正確的角度看待假設句型的文法規則。過程中，學生將回顧過去學習的規則，並藉由真實生活中的例句打破傳統迷思及錯誤觀念，最後從「溝通目的」為出發點，慢慢重建理解，並且串聯過去所學的動詞變化規則。

2. 句子偵探：先看用途，再看時態

每一題要同時判斷兩件事：這句主要是在做什麼，以及 if 子句使用的是哪一種時態。一般規律中，if 後會附上 (when)，表示此處也能用 when 表達「每當」；其他題目保留 if，避免把「如果」誤當成「當……時」。答對後，確認答案按鈕會變成下一題按鈕。

Context（情境）

A child asks why running in the rain is dangerous. You explain what usually happens.

（孩子問為什麼在雨中奔跑很危險。你解釋一般會發生的情況。）

If (when) it rains, the ground gets wet.

這句的主要用途

if 子句使用的時態

3. 規則探索：為什麼想像過去要用完成式？

用同一組條件與後續行動，分別描述對未來與過去的另一種設想。

Condition（條件）：win three million dollars（中三百萬）
Subsequent action（後續行動）：buy a sports car（買一輛跑車）

情境 A：設想未來

你還沒參加明天的抽獎。先暫時設想另一種生活，並不是在作購車承諾。

If I three million dollars tomorrow, I a sports car.

情境 B：設想過去

你上個月沒有中獎，也沒有買跑車。回頭設想：如果那次中獎，後來本來會做什麼？

If I three million dollars last month, I a sports car.

觀察更多例句，找出規律

兩句都用 won / would buy 時，拿掉時間詞，會剩下完全相同的句子。tomorrow 和 last month 雖提供時間線索，動詞形式卻沒有清楚區分這兩種設想。觀察以下各五句，看看英文如何標示差別。

設想未來

  1. If I won a prize tomorrow, I would celebrate with my family.
  2. If she moved here next year, we would see her more often.
  3. If we left early tomorrow, we would catch the first train.
  4. If he got the job next week, he would rent a flat nearby.
  5. If they invited me next month, I would attend the party.

設想過去

  1. If I had won a prize yesterday, I would have celebrated with my family.
  2. If she had moved here last year, we would have seen her more often.
  3. If we had left early yesterday, we would have caught the first train.
  4. If he had got the job last week, he would have rented a flat nearby.
  5. If they had invited me last month, I would have attended the party.

哪個整理最符合這十個例句？

進一步思考：為什麼用完成式？

那為什麼想像過去常會出現 had + p.p.？

整理：
1. 設想另一種現實時，英文常先把形式往過去移，做出距離感。
2. 但如果要明確表示「想像的是過去的另一種走向」，光靠過去式不夠。
3. 這時會進一步用完成式，把焦點放在一個更早的行動，以及它後來本來可能造成的不同結果。
4. 所以它不只是「過去」，而是「較早的動作 + 後來結果本可不同」這種 framing，剛好和 perfect 的視角有重疊。

三種用途差在哪裡？

都有「如果」，也都能提到尚未發生的事。請看說話者是在說規律、做實際提議，還是暫時換個情況來想。

描述事實 / 規則：通常都這樣

If (when) we hire someone, we give them training.

「我們每次錄用新人，都會提供訓練。」在說公司的慣例，讓看/到這句話的人藉此建立對未來合理的預期。

描述意願 / 選擇：條件成立，我就這樣做

If you accept the job, I will arrange your training.

「你若接受這份工作，我就安排訓練。」這是實際提議或承諾；讓看/到這句話的人據此作決定。

設想另一種現實：先假定換個情況，想想會怎樣

If I gave you the job, what training would you need?

「先假設我給你這份工作，你會需要什麼訓練？」是在試想一個與現實架空/沒有連結的情境，這句本身沒有承諾要錄用或給予訓練，單純是單純針對給予的情境進行假想討論，與承諾或規則/規律的陳述不同，討論的內容不具備現實世界中約束力。

「設想」不等於「不可能」。同一件事可以用不同角度談；用途也可能重疊，要一起看上下文。if 是「如果」；when 常表示「當……時／每當」，不能在每句中直接互換。
